# Core Java Programming & Logic Implementations

A structured collection of Java applications demonstrating core object-oriented principles, algorithmic problem-solving, advanced array manipulation, and comprehensive File I/O operations.

## Featured Implementations

### 1. Real-World Applications & Date Processing
* **Age Calculator (`ty.java`):** A robust date validation and calculation engine. It accurately computes the exact age of a user in years, months, and days based on their Date of Birth (DOB), accounting for complex edge cases like leap years.

### 2. Comprehensive File I/O Operations
* **Data Management System:** Programs demonstrating full CRUD (Create, Read, Update, Delete) operations within Java. Features reading from and writing to both text and binary files, modifying existing records, deleting entries, and copying data between files using `FileWriter`, `PrintWriter`, `FileReader`, and `BufferedReader`.

### 3. Number Theory & Mathematical Logic
* **Circular Primes (`circular.java`):** An algorithm to detect circular prime numbers through digit extraction and left/right rotation logic.
* **Circular Magic Numbers (`cmag.java`):** Identifies composite magic numbers within a dynamically given range.
* **Digit Frequency & Filtering (`tanish.java`):** Implements logic to filter out numbers with repeating digits in a given range.

### 4. Array Algorithms & Permutations
* **Maximum Combination Finder (`n1.java` & `n2.java`):** Handles array permutations and rotation logic. It evaluates all possible combinations of a given set of numbers to calculate the maximum possible weighted sum.
* **Profit Optimization (`stock.java`):** Implements an algorithm to find the maximum difference (profit) between sequential elements in an array.

### 5. Object-Oriented Reusability
* **Modular Functions:** Throughout the repository, code is structured using reusable methods and functions to ensure scalability and adherence to DRY (Don't Repeat Yourself) principles.

## Technologies & Concepts Used
* **Language:** Java (JDK)
* **Core Concepts:** Object-Oriented Programming (OOP), Scanner/DataInputStream parsing, File I/O (Text & Binary), Looping & Control Structures, Array Manipulation.
